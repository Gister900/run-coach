# 🏃 RUN COACH — ผู้ช่วยแนะนำการวิ่งบนลู่ 8 สัปดาห์

แอปจับเวลา/คุมจังหวะวิ่งบนลู่ไฟฟ้า โปรแกรม 8 สัปดาห์ × 7 วัน — บอกความเร็ว ความชัน โซนหัวใจ และนับถอยหลังแต่ละช่วงให้อัตโนมัติ. ทำงานในไฟล์เดียว (HTML+JS) ไม่ต้องต่อเน็ตหลังโหลดครั้งแรก.

## ฟีเจอร์
- **โปรแกรม 8 สัปดาห์**: Easy / Interval / Recovery / Tempo / Long / Rest แต่ละวันคุม segment ความเร็ว+ความชันให้ครบ
- **จับเวลาอัตโนมัติ** + เสียงบี๊บนับถอยหลัง 3-2-1 + สั่น (vibrate) + กันจอดับ (Wake Lock)
- **โซนหัวใจ** คำนวณจากอายุ (Max HR = 220 − อายุ) โชว์ช่วง bpm ของแต่ละช่วง
- **ปรับความเร็วได้ทั้งแผน** ±0.5 กม./ชม. (ปุ่ม +/−)
- **จำค่า** อายุ/สัปดาห์/วัน ผ่าน `localStorage` (ปิดแล้วเปิดใหม่ค่ายังอยู่)
- **PWA**: Add to Home Screen ใช้เต็มจอเหมือนแอป + เปิด offline ได้

## ใช้งานบนมือถือ
1. เปิด URL (GitHub Pages) ใน Safari/Chrome บนมือถือ
2. กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** (Add to Home Screen)
3. กดไอคอนคนวิ่งบนจอ → เปิดเต็มจอ ใช้ได้แม้ไม่มีเน็ต
4. ⚙️ ตั้งค่า → ใส่อายุให้คำนวณโซนหัวใจแม่นขึ้น

> ⌚️ คู่กับ Apple Watch: เปิด Workout → **Indoor Run** ก่อนเริ่ม จะเห็นหัวใจสดๆ บนข้อมือ คอยให้ตรงกับช่วง bpm ที่แอปบอก

## โครงสร้างไฟล์
```
run-coach/
├── index.html      ← แอปทั้งหมด (UI + logic + timer engine)
├── manifest.json   ← ข้อมูล PWA (ชื่อ/สี/ไอคอน)
├── sw.js           ← service worker (cache offline)
└── icons/
    ├── icon.svg    ← ต้นฉบับไอคอน (vector)
    ├── icon-192.png
    └── icon-512.png
```

## พัฒนา / รันในเครื่อง
PWA ต้องเสิร์ฟผ่าน http (ไม่ใช่ `file://`) เพื่อให้ service worker ทำงาน:
```bash
cd run-coach
python3 -m http.server 8080
# เปิด http://localhost:8080
```

## Deploy
อยู่บน **GitHub Pages** (repo ส่วนตัว) — push ไป branch `main` แล้วเปิด Pages ที่ root จะได้ URL อัตโนมัติ.
